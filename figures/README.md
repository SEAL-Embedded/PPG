# Manuscript figures

Each figure ships as a `.pdf` (vector, for submission) and a `.png` (preview).

| File | Manuscript figure | Cited in |
|------|-------------------|----------|
| `figure3_pipeline_flowchart.*` | Figure 3 — signal-processing pipeline flowchart | Methods |
| `figure4_representative_waveforms.*` | Figure 4 — representative PPG waveforms | Results |
| `figure5_sqi_by_site.*` | Figure 5 — SQI by body site | Results |
| `figure6_bland_altman_hr.*` | Figure 6 — Bland–Altman, heart rate (PPG − ECG) per site | Results |
| `figure7_sqi_by_site_fst.*` | Figure 7 — SQI by body site, stratified by Fitzpatrick skin type | Results |
| `figure8_bland_altman_sdnn.*` | Figure 8 — Bland–Altman, SDNN (PPG − ECG) per site | Results |
| `figure9_agreement_heatmap.*` | Figure 9 — Pearson r heatmap: site × metric × skin group | Results |

Figures 6–9 are generated by the `make_figure*.py` scripts in this directory
(run from the repo root with `.venv/bin/python figures/make_figureN_*.py`);
shared Bland–Altman plotting lives in `_ba_common.py`. Sessions label the
head-mounted channel "forehead" — the scripts alias it to the manuscript's
"temple".
